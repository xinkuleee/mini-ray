## 恢复方法

完整614路径动作表仍保存在[project-cleanup-plan.json](project-cleanup-plan.json)，没有因文档压缩而删除。K0原始机器清单和范围索引固定于提交1a3822877d4d587e95bc2a4b72f7ad5d38fc998f；本地可用git show读取该提交的docs/project-cleanup-plan.json和docs/project-cleanup-index.md。该提交尚未发布时，不以远端链接代替本地恢复证明。

读取机器索引的`fixed_git_spec`或`git_blob_oid`。例如用Python保存Git标准输出原字节，再与该条`raw_sha256`比较：

```python
import hashlib, subprocess
from pathlib import Path
blob_oid = "53937e4c6b0a1c84592e6ef2016a30a243e69585"
raw = subprocess.check_output(["git", "cat-file", "blob", blob_oid])
print(hashlib.sha256(raw).hexdigest())
Path("recovered-document.bin").write_bytes(raw)
```

Git固定URL同时提供人读入口；若要运行历史实验，检出完整固定版本并使用其依赖/运行说明，不把单个旧源码或测试复制回当前运行时。
